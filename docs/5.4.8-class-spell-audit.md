# 5.4.8 class spell audit

This log records the class-by-class checks made against the local 5.4.8 data
set and the live world database. A class is marked clean only after the
worldserver builds, validates its spell scripts, and reaches `World
initialized` without a new spell or data error.

The client protocol build is 18414. The bundled DB2 files carry Blizzard's
18273 data header, which is also the build selected by this repository's
5.4.8 extractor and is therefore expected rather than a mixed-version error.

## Death Knight

- `Talent.dbc`: 18 Death Knight records, arranged as six rows of three
  talents; all referenced talent spells exist in `Spell.dbc`.
- World database: 102 active `spell_dk*` script bindings.
- Checked the disease, rune/runic-power, presence, Blood Shield, Dark
  Simulacrum, control, survival, level-75 resource, and level-90 talent paths,
  together with the active glyph handlers.
- Corrected Anti-Magic Zone for its patch 5.4 redesign: it now reduces magic
  damage by 40% for three seconds with no total absorb cap and no Strength
  scaling. Both the active area-trigger path and the legacy area-aura path use
  the same behavior.
- Result: worldserver rebuilt successfully; startup validation completed with
  4,525 scripts and no new spell/DBC error.

## Data-set and final startup validation

- Audited 451 bundled data files: 393 DBC and 58 DB2 files. All 58 DB2 files
  have the `WDB2` signature and build header 18273 expected by the repository's
  5.4.8 extractor; the server protocol remains client build 18414.
- `Talent.dbc` contains 198 records: exactly 18 for each of the 11 classes,
  with six rows and three choices per row. Every referenced talent spell is
  present in `Spell.dbc`.
- The final RelWithDebInfo worldserver build completed successfully. A fresh
  start validated 4,525 spell scripts and reached `World initialized` in 23
  seconds with zero stderr output and zero new `DBErrors.log` bytes.
- Removed seven impossible manual spawns of transport template 149045
  (`Scaffold Cars`) and their event links. Transports are map/client driven,
  and these rows were the source of the remaining startup warnings.
