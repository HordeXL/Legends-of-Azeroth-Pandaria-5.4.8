# 5.4.8 class spell audit

This log records the class-by-class checks made against the local 5.4.8 data
set and the live world database. A class is marked clean only after the
worldserver builds, validates its spell scripts, and reaches `World
initialized` without a new spell or data error.

The client protocol build is 18414. The bundled DB2 files carry Blizzard's
18273 data header, which is also the build selected by this repository's
5.4.8 extractor and is therefore expected rather than a mixed-version error.

## Hunter

- `Talent.dbc`: 18 Hunter records, arranged as six rows of three talents; all
  referenced talent spells exist in `Spell.dbc`.
- World database: 107 active `spell_hun*` / `spell_hunt*` script bindings.
- Checked the scripted talent paths for Binding Shot, Fervor, Dire Beast,
  Thrill of the Hunt, A Murder of Crows, Blink Strikes, Lynx Rush, Glaive
  Toss, Powershot, and Barrage. The remaining talents are data-driven.
- Checked the scripted glyph paths, including Mend Pet's 5.4 100% dispel,
  Misdirection, Camouflage, Explosive Trap, Deterrence, Distracting Shot,
  Aspect of the Cheetah, and Lesser Proportion.
- Checked the 5.4 Stampede PvP damage reduction and the specialization-specific
  Tier 16 effects against the bundled spell effects.
- Result: no Hunter-specific source or database correction was required.
  Startup validation completed with 4,525 scripts and no new spell/DBC error.

- Checked the scripted talent paths for Chi Wave, Zen Sphere, Chi Burst, Power

  1,000 ms amplitude in the bundled data, but the script divided each absorbed
