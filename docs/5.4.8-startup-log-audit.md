  playerbot configuration templates and the installed `playerbots.conf`.

  teleport distance retain the code defaults of `poolbot`, `200` and `100.0`.

## Verification

isolated localhost server with INFO logging to include warnings hidden by the
installed root ERROR threshold. The five reported startup messages disappeared.
All 4,555 spell scripts validated, and the final Win64 RelWithDebInfo server
initialized in 23 seconds. `DBErrors.log` remained empty.

`contrib/startup_548/test-mmap.ps1` in an x64 MSVC developer shell after building

### Client-source follow-up

The user requires correcting causes or supplying verified missing data, not
silencing errors merely to make a log look clean. None of the runtime fixes
above lowers a logging threshold, removes a diagnostic, disables validation or
turns missing/corrupt MMAP data into success. The successful repeated-load case
is explicitly covered by a real-loader test, including an absent-file control.

The empty generator result was subsequently checked against the original client
archives, since it alone cannot prove that extraction inputs are complete.
`contrib/startup_548/client_terrain.cpp` reads the same ordered world/expansion
and update/cache MPQ chain as `map_extractor`, without modifying game assets.
Results are recorded in `contrib/startup_548/client-terrain-20261005.csv`:

- All eight queried Darkmoon Faire / Mogu Island coordinates have WDT flags 2,
  with the terrain-presence bit unset; the corresponding ADTs are absent as
  specified by the client.
- The other eight ADTs are readable with all 256 terrain chunks. Their original
  height ranges are below -500: Eastern Kingdoms approximately -519 to -510,
  Outland -1190, Northrend -653. `map_extractor/System.cpp` deliberately clamps
  heights below `CONF_use_minHeight = -500`, producing the installed flat
  no-height records. This explains the inputs used by the navigation generator.
- Four populated Eastern Kingdoms tiles were positive controls. The independent
  client-reader height ranges agree with the installed extracted map headers;
  all four have navigation files, and tile 31,31 passes the repeated-load test.

These findings support the classification of these specific terrain coordinates;
they do not certify all client assets or justify suppressing future MMAP failures.
No extra runtime change or invented replacement tile was made in this follow-up.
The client reader accepts a Data directory and a text file containing one
`map gx gy` triple per line. It can be built in an x64 MSVC developer shell with
`/std:c++17 /MD /DWIN32 /Idep/StormLib/src`, linking the existing RelWithDebInfo
`StormLib.lib`, `user32.lib` and `advapi32.lib`. The executable and full local
reports are under `Build/startup-audit-20261005/`.

Messages about empty optional tables, disabled auction bot/automatic SQL updates,
and existing database command-permission overrides are informational. No further
startup error was found. The Acid Rain quest itself was not played in a client.
