# Startup log audit - 2026-10-05

## Fixed

- Added all four `AiPlayerbot.PlayerbotPool.*` defaults to both distributed
  playerbot configuration templates and the installed `playerbots.conf`.
  The separate account pool remains disabled (`Enabled = 0`); prefix, count and
  teleport distance retain the code defaults of `poolbot`, `200` and `100.0`.
  The missing-key message names the main worldserver file, but the module loads
  `playerbots.conf` into the same configuration manager before reading these keys.
- Bound spell 104527 (Poison Blossom, Acid Rain vehicle quest) effect 0 to
  `SPELL_EFFECT_SCRIPT_EFFECT` (77), matching the local 5.4.8 DBC. The previous
  `SPELL_EFFECT_FORCE_CAST` (140) registration failed validation, so the existing
  area attack handler never ran. No SQL change was needed; its binding exists.
- Made an already loaded MMAP tile report successful loading. Previously it
  returned false, producing a misleading missing-navigation warning. The fix
  does not add a second tile or change failure handling for absent files.

## Verification

Reviewed the complete installed `Server.log` and `DBErrors.log`, then started an
isolated localhost server with INFO logging to include warnings hidden by the
installed root ERROR threshold. The five reported startup messages disappeared.
All 4,555 spell scripts validated, and the final Win64 RelWithDebInfo server
initialized in 23 seconds. `DBErrors.log` remained empty.

The real MMAP loader regression failed before the fix (`first=1 repeated=0`)
and passed after it. It checks initial/repeated loading of Eastern Kingdoms
tile 31,31, unchanged mesh and tile count, rejection of an absent tile without
changing the count, unloading and reloading. Run
`contrib/startup_548/test-mmap.ps1` in an x64 MSVC developer shell after building
the common library; it uses the existing local navigation files read-only.

The four false Eastern Kingdoms center-tile warnings no longer occur. Detailed
logging still reports 16 absent navigation tiles:

| Map | Tile coordinates |
| --- | --- |
| Eastern Kingdoms (0) | 48,27 |
| Outland (530) | 32,32; 31,32; 31,31 |
| Northrend (571) | 31,31; 31,32; 32,31; 32,32 |
| Darkmoon Faire (974) | 31,31; 31,32; 32,31; 32,32 |
| Mogu Island Daily Area (1064) | 31,31; 31,32; 32,31; 32,32 |

These coordinates have no terrain file or contain a no-height terrain stub
(`MAP_HEIGHT_NO_HEIGHT`, height -500). A single-tile generation check for each,
using the installed extractor and existing terrain/VMAP inputs, exited normally
without generating a navigation tile or reporting errors. Generation ran in a
separate output directory; no installed maps, VMAPs or MMAPs were changed. These
empty-tile warnings were retained rather than disabling navigation or hiding
missing-file failures globally. This does not establish navigation coverage of
every playable area.

Messages about empty optional tables, disabled auction bot/automatic SQL updates,
and existing database command-permission overrides are informational. No further
startup error was found. The Acid Rain quest itself was not played in a client.
