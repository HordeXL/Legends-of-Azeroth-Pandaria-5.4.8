# Profession effects and bonuses audit - 2026-10-05

## Fixes

- Profession-restricted gems now lose and regain their stats when the required
  skill is removed, learned again or crosses the required rank. This includes
  engineering cogwheels whose requirement exists on the gem item rather than the
  enchantment record. Enchant, gem and blacksmith socket requirements are checked
  together so an inactive gem is not removed again and an active gem is not
  applied twice. Existing permanent and temporary skill bonuses are included.
- Learning a profession registers the skill and its bonuses before restoring
  enchants already on equipped items. Previously, the restoration could see a
  missing skill and fail. An unknown enchant no longer stops the entire scan.
- On-use engineering tinkers now check the enchantment's profession rank and
  character level, matching the checks already present for combat enchants.
- Pandaria Swordguard Embroidery now applies its 4,000 attack power to both
  melee and ranged effects. The generic proc handler previously supplied the
  override only to melee, leaving ranged attack power at the child spell's
  1,000-point default. Other triggered spells retain their existing behavior.
- Mixology now uses explicit additions for the modern flasks and elixirs below.
  Mantid Elixir previously received 720 extra armor instead of 480; the five
  Cataclysm flasks had no stat bonus entry. The other listed Pandaria totals
  remain unchanged. Existing alchemy/known-recipe eligibility and doubled
  duration are preserved, as are older elixir multiplier rules.

Cataclysm flask bonus. Its Steelskin base differs from the local DBC, so that
base was not copied.

## Coverage and existing bonuses

The reproducible inventory starts with all 11 primary and four secondary
profession skill lines, follows client trigger links, crafted item spells and
enchantment spell effects, and includes selected child spells used directly by
scripts. It contains 7,286 spell identifiers, 602 enchantments and 120 automatic
skill-spell rows. This includes legacy and unused records.

Reviewed existing bonus records include:

- Mining Toughness (102163): 480 stamina at skill 600; Skinning Master of Anatomy
  (102219): 480 critical strike rating at 600. The rank chains and automatic
  skill-spell entries are present.
- Herbalism Lifeblood (121279): 2,880 haste for 20 seconds at skill 600, with its
  existing healing effect.
- Engineering Synapse Springs: the scripts choose the highest primary stat and
  pass through the correct 480/1,920 value for the older/Pandaria versions.
- Tailoring Lightweave and Darkglow: the proc driver supplies 2,000 intellect and
  3,000 spirit respectively; the lower defaults on their child spells do not
  need a global override.
- Enchanting ring bonuses, Jewelcrafting gems, Inscription shoulder inscriptions,
  Leatherworking bracer enhancements and Blacksmithing sockets retain their
  client-defined amounts and profession requirements. Profession selection by
  itself does not grant crafting benefits that require applying an enhancement.

## Visual references

Of the roots and their children, 7,285 exist in Spell.dbc. The audit followed
282 spell visuals, 386 kits, 33 attachments and 41 missiles with zero broken
visual references. Enchantment ItemVisuals/ItemVisualEffects references also
have zero missing records.

All 275 unique referenced model files were found in the local 5.4.8 client's
93 readable archives. Item model paths ending in `.MDX`, regardless of case,
are normalized to `.m2` for this check. No client files were modified.

One unresolved root remains: Jewelcrafting SkillLineAbility row 21173 names
spell 66587, absent from Spell.dbc. It is not an automatic skill reward, and the
core skips missing spell records. This obsolete reference was recorded rather
than inventing a spell or visual for it. Passive/helper spells and many armor
enchants intentionally have no visual.

These are data-reference, asset-presence and code checks. They do not establish
that every recipe, proc frequency, animation or aura has been exercised and
rendered correctly in a live client.

## Validation and installation

- 41 profession regression checks pass, extracting the changed production
  functions into the fixture. Coverage includes amounts, both Swordguard
  effects, combined profession requirements, rank transitions, skill bonuses,
  missing records, unequipped items and on-use tinker eligibility. An additional
  source-order check protects skill registration before restoration.
- All 63 existing character-visual regression checks still pass.
- Win64 RelWithDebInfo worldserver builds successfully. The build output is
  installed at `Build/bin/RelWithDebInfo/worldserver.exe`; the previous executable
  and symbols are backed up in `Build/server-before-professions-20261005/`.
- An isolated smoke server initialized in 24 seconds, produced an empty
  `DBErrors.log`, and exited normally through `server shutdown 0`. It was left
  stopped. No SQL migration is required.

Run `contrib/profession_548/test.ps1` in an x64 MSVC developer environment.
Run `contrib/profession_548/audit.ps1` for the local DBC/database inventory; it
reads the configured world database without modifying it. Reports and build
logs are under `Build/profession-audit/`. Client model verification uses the
existing `contrib/spell_visual_548/check_models.cpp` utility with the combined
spell and item model lists.
